CYD Stock Ticker Architecture

A 320x240 LVGL stock dashboard for the Cheap Yellow Display. The UI stays on core 1, networking stays on core 0, and the stock-api proxy keeps HTTPS, yfinance, history, and logo resolution off the device.

2 tasks UI and network work are pinned to separate ESP32 cores.
32 KB Device LVGL heap budget. The simulator overrides this upward.
64x64 Runtime logos arrive from the API as transparent PNG assets.
192 KB LittleFS partition; keep baked data/ content tiny.

Task Boundaries

  • UI task: owns LVGL calls, screen transitions, chart rendering, touch processing, and the runtime decoded-logo cache.
  • Network task: owns STA/AP WiFi, HTTPS stock requests, runtime logo downloads, the captive portal, and the `/settings` web admin.
  • Stores: `QuoteStore` and `SettingsStore` provide mutex-protected handoff points so neither task reaches across the boundary directly.
  • LVGL invariant: `LV_OS_NONE` is deliberate. All LVGL access stays behind the project lock instead of LVGL's FreeRTOS OSAL.

Data Flow

1. Settings

On boot, LittleFS settings seed WiFi credentials, API token, symbols, refresh interval, and favourites.

2. Quotes

The network task fetches /stock/{symbol} with bearer auth and a non-empty User-Agent, then stores last price, change, and sparkline closes.

3. History

Detail range taps request /history/{symbol}?range=1d|5d|1w|1mo|6mo; generation checks drop stale responses.

4. Render

The UI task snapshots the stores, draws list/detail screens, formats history, and uses cached logos or fallback badges.

Logo Pipeline

  • Embedded logos come from sim/logo_src/*.png through sim/build_logo_arrays.py into src/ui/logos_data.cpp.
  • Missing logos are downloaded from stock-api as /logos/<SYMBOL>.png in LittleFS.
  • Runtime logos are decoded with LovyanGFX PNGLE, alpha-trimmed, resampled into transparent ARGB image buffers, and mounted through LVGL.
  • The PNG decoder is prepared for initial list construction and released afterward so TLS has enough contiguous DRAM for future HTTPS calls.

Storage Rule

Keep data/ near-empty. The LittleFS partition is small, and baked filesystem content competes with runtime-fetched logos and settings. Source PNGs for embedded logos belong in sim/logo_src/, not data/logos/.

UI Surfaces

  • List: rows show logo or badge, symbol, price, percent change, and sparkline.
  • Detail: selected symbol, current price, range gain/loss, and an area-filled chart with range tabs.
  • Settings screen: read-only device status with LAN URL for the web admin.
  • Web admin: LAN form for token, refresh interval, and symbol add/delete.

Simulator

  • Build with sim/build_sim.ps1; it drives the MSYS2/MinGW toolchain directly.
  • --window opens an SDL preview; --headless --out=file.png renders screenshots for review.
  • --web-settings=file.html emits the same browser settings UI used by firmware.
  • The simulator links the same UI sources and uses a larger LVGL heap to keep desktop testing ergonomic.
